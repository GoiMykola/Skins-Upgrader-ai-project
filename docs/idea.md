# Ідея застосунку: GoiCoins Skin Simulator

Вебзастосунок "GoiCoins Skin Simulator" — це симулятор інвентарю та крафту/апгрейду ігрових предметів для геймерів на базі суто віртуальної валюти (GoiCoins), без використання реальних грошей та азартних ставок. Користувачі отримують стартові та щоденні віртуальні монети, збирають колекцію скінів, виконують ігровий апгрейд предметів різної рідкісності та змагаються у відкритому рейтингу колекціонерів.

## Відповіді на питання для формування MVP

1. **Ролі користувачів:** У системі є дві ролі — "Звичайний гравець" та "Адміністратор". Гравець може переглядати каталог, симулювати отримання скінів, здійснювати апгрейди, керувати власним інвентарем та переглядати публічні профілі; адміністратор керує каталогом скінів (додавання, редагування параметрів) та обробляє скарги користувачів.
2. **Гостьовий доступ:** Незареєстрований користувач має право переглядати загальний каталог скінів та публічну таблицю лідерів, але будь-яка спроба симуляції чи апгрейду перенаправляє його на форму авторизації.
3. **Публічні дані та модерація:** Користувачі можуть відкривати інвентарі інших гравців за нікнеймом. У профілі доступна форма подання скарги на порушення (образливий нікнейм/аватар), які надходять на розгляд адміністратору.
4. **Сутності даних:** 
   - Профіль користувача (User)
   - Каталог скінів (SkinItem)
   - Інвентар користувача (UserInventoryItem)
   - Спроба апгрейду (UpgradeTransaction)
5. **Зв'язок "багато до багатьох":** Зв'язок реалізовано між користувачами та скінами каталогу через проміжну таблицю `UserInventoryItem` (один користувач володіє багатьма скінами, один тип скіна може бути в інвентарях багатьох користувачів з фіксацією дати отримання).
6. **Цінність предметів:** 1 GoiCoin еквівалентний умовній базовій ціні скіна в каталозі (значення фіксуються адміністратором згідно з відкритими ігровими ринками).
7. **Невдача під час апгрейду:** У разі невдалої спроби апгрейду вхідний предмет безповоротно списується та видаляється з інвентаря гравця.
8. **Стартовий баланс:** Користувач отримує 1000 стартових GoiCoins при реєстрації для здійснення перших спроб апгрейду.
9. **Формування рейтингу:** Публічний рейтинг базується на сумарній віртуальній вартості всіх активних предметів в інвентарі користувача.
10. **Межі MVP (відкладені функції):** До першої версії свідомо не входять прямий P2P-обмін скінами між гравцями, аудіоефекти, складна canvas-анімація колеса апгрейду та система промокодів.

## Складна складова (вимога В4)

Для виконання вимоги В4 обрано технологію **Supabase Realtime**. Вона забезпечує функцію відкритої "Живої стрічки апгрейдів" (Live Activity Feed), де всі активні користувачі в реальному часі без перезавантаження сторінки бачать результати успішних покращень предметів іншими гравцями.
