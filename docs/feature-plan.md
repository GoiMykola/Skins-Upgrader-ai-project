# Фіче-план проєкту: GoiCoins Skin Simulator

## 1. Функції першої версії (MVP) — 7 функцій

| № | Назва та опис | Джерело | Статус | Обґрунтування |
|---|---|---|---|---|
| Ф1 | Автентифікація та стартовий баланс: реєстрація, вхід і нарахування 1000 стартових GoiCoins | студент | MVP | Базова потреба для ідентифікації гравця та початкових спроб |
| Ф2 | Каталог скінів та власний інвентар: перегляд бази скінів та відображення отриманих предметів | студент | MVP | Ключова сутність симулятора інвентаря |
| Ф3 | Симулятор апгрейду скінів: розрахунок шансу, вибір цілі, спалювання або отримання скіна | студент | MVP | Основна ігрова механіка застосунку |
| Ф4 | Жива стрічка апгрейдів (Realtime, В4): миттєве оновлення стрічки успішних крафтів гравців без оновлення сторінки | студент | MVP | Реалізація обов'язкової складної складової В4 |
| Ф5 | Публічний рейтинг колекціонерів: таблиця лідерів за сумарною вартістю інвентаря в GoiCoins | студент | MVP | Створює змагальний елемент для користувачів |
| Ф6 | Публічний профіль та перегляд інвентаря: перегляд вітрини предметів іншого гравця за посиланням або нікнеймом | студент | MVP | Дозволяє користувачам ділитися колекціями (вимога В1) |
| Ф7 | Подання скарг на профіль (Модерація, В6): надсилання скарги на неприйнятний нікнейм або аватар користувача | студент | MVP | Обов'язкова вимога безпеки та модерації контенту |

## 2. Відкладені функції

| № | Назва та опис | Джерело | Статус | Обґрунтування |
|---|---|---|---|---|
| Ф8 | ШІ-генератор лору та модифікації скінів (В5) | модель | відкладено | Заплановано на практичну роботу № 6 |
| Ф9 | Щоденне нарахування монет за розкладом (Cron) | модель | відкладено | Для старту MVP достатньо разового стартового балансу |
| Ф10 | Панель адміністратора для модерації та каталогу | модель | відкладено | Керування базою на етапі MVP здійснюється через дашборд Supabase |
| Ф11 | Прямий P2P-обмін скінами між гравцями | студент | відкладено | Складна транзакційна логіка, відкладена на наступні версії |
| Ф12 | Canvas-анімація та звуки апгрейду | студент | відкладено | Для першої версії достатньо стандартної зміни стану інтерфейсу |
| Ф13 | Система промокодів | студент | відкладено | Маркетингова механіка, не критична для MVP |
| Ф14 | Аналітика успішності та ROI гравця | модель | відкладено | Надлишкова аналітика, не потрібна для базової гри |
